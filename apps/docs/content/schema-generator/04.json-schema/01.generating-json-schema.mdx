title: Generating JSON Schema

## Overview

The `generateJsonSchema` function takes a parsed column structure (produced by `json-column-parser`) and outputs a valid [JSON Schema Draft-07](https://json-schema.org/draft-07) document. This schema is used downstream for validating and transforming API responses.

## generateJsonSchema Function

```typescript
import { generateJsonSchema } from "@lakeql/schema-generator/json-schema"
import type { JSONSchema7 } from "json-schema"

// Input: parsed columns from json-column-parser
const parsedColumns = {
  id: "varchar",
  name: "varchar",
  amount: "double",
  created_at: "timestamp(3)",
  tags: ["varchar"],
  metadata: {
    source: "varchar",
    version: "bigint",
  },
}

const schema: JSONSchema7 = generateJsonSchema(parsedColumns)
```

## Output Structure

The output follows JSON Schema Draft-07 format with `additionalProperties: false` set at every level:

```json
{
  "$schema": "https://json-schema.org/draft-07/schema#",
  "type": "object",
  "additionalProperties": false,
  "properties": {
    "id": { "type": "string" },
    "name": { "type": "string" },
    "amount": { "type": "number" },
    "created_at": { "type": "string", "format": "date-time" },
    "tags": {
      "type": "array",
      "items": { "type": "string" }
    },
    "metadata": {
      "type": "object",
      "additionalProperties": false,
      "properties": {
        "source": { "type": "string" },
        "version": { "type": "integer" }
      }
    }
  }
}
```

## Trino to JSON Schema Type Mapping

| Trino Type                        | JSON Schema Type | Format            |
| --------------------------------- | ---------------- | ----------------- |
| `varchar`                         | `string`         | —                 |
| `double`, `float`, `decimal(...)` | `number`         | —                 |
| `integer`, `bigint`               | `integer`        | —                 |
| `boolean`                         | `boolean`        | —                 |
| `timestamp(...)`                  | `string`         | `date-time`       |
| `date`                            | `string`         | `date`            |
| `array(T)`                        | `array`          | items: mapped T   |
| `row(...)`                        | `object`         | nested properties |

## Handling Complex Types

### Arrays

Arrays of primitives map directly:

```typescript
// Input: tags: ["varchar"]
// Output: { "type": "array", "items": { "type": "string" } }
```

Arrays of objects produce nested object schemas:

```typescript
// Input: items: [{ name: "varchar", quantity: "bigint" }]
// Output: { "type": "array", "items": { "type": "object", "properties": {...} } }
```

### Nested Objects

Objects (from Trino `ROW` types) are recursively converted:

```typescript
// Input: address: { street: "varchar", city: "varchar", zip: "varchar" }
// Output: { "type": "object", "additionalProperties": false, "properties": {...} }
```

## Usage in LakeQL

The generated JSON schema serves two purposes:

1. **Response transformation** — Validates that query results conform to the expected structure before sending them to clients
2. **Input to other generators** — The GraphQL schema generator consumes JSON Schema to produce model definitions
