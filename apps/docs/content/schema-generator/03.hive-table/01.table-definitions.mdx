## Overview

The Hive table sub-module generates `CREATE TABLE IF NOT EXISTS` statements compatible with Trino's Hive connector. It maps JSON Schema field definitions to SQL types and supports nested structures (ROW types) and arrays.

## generateCreateTableStatement

```typescript
import { generateCreateTableStatement } from "@lakeql/schema-generator/hive-table"

const ddl = generateCreateTableStatement({
  schema: "analytics",
  tableName: "events",
  bucketName: "my-data-lake",
  bucketPath: "raw/events/",
  definition: {
    id: { type: "string" },
    timestamp: { type: "string", format: "date-time" },
    duration: { type: "number" },
    tags: { type: "array", items: { type: "string" } },
    metadata: {
      type: "object",
      properties: {
        source: { type: "string" },
        version: { type: "integer" },
      },
    },
  },
})
```

Output:

```sql
CREATE TABLE IF NOT EXISTS "analytics"."events" (
  "id" varchar,
  "timestamp" timestamp(3),
  "duration" double,
  "tags" array(varchar),
  "metadata" ROW(source varchar, version bigint)
)
WITH (
  external_location = 's3://my-data-lake/raw/events/',
  format = 'PARQUET'
)
```

## Type Mapping

| JSON Schema Type | Format      | SQL Type               |
| ---------------- | ----------- | ---------------------- |
| `string`         | —           | `varchar`              |
| `string`         | `date-time` | `timestamp(3)`         |
| `integer`        | —           | `bigint`               |
| `number`         | —           | `double`               |
| `boolean`        | —           | `boolean`              |
| `array`          | —           | `array(element_type)`  |
| `object`         | —           | `ROW(field type, ...)` |

## generateSqlSchema

For generating just the column definitions without the full CREATE TABLE wrapper:

```typescript
import { generateSqlSchema } from "@lakeql/schema-generator/hive-table"

const fields = generateSqlSchema({
  definition: {
    name: { type: "string" },
    age: { type: "integer" },
    active: { type: "boolean" },
  },
})
// [["name", "varchar"], ["age", "bigint"], ["active", "boolean"]]
```

Returns an array of `[fieldName, sqlType]` tuples.

## Nested Structures

Objects are mapped to Trino `ROW` types, and arrays of objects become `array(ROW(...))`:

```typescript
const ddl = generateCreateTableStatement({
  schema: "logs",
  tableName: "requests",
  bucketName: "data-lake",
  bucketPath: "logs/requests/",
  definition: {
    id: { type: "string" },
    headers: {
      type: "array",
      items: {
        type: "object",
        properties: {
          key: { type: "string" },
          value: { type: "string" },
        },
      },
    },
  },
})
```

Produces:

```sql
CREATE TABLE IF NOT EXISTS "logs"."requests" (
  "id" varchar,
  "headers" array(ROW(key varchar, value varchar))
)
WITH (
  external_location = 's3://data-lake/logs/requests/',
  format = 'PARQUET'
)
```
