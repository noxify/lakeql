The LakeQL CLI (`@lakeql/cli`, binary `lakeql-cli`) is the generation and introspection tool. It reads your `lakeql.config.ts`, connects to a data source through its adapter, and generates the typed endpoint files the API server serves.

You reach for it to initialize a project, explore a data source, and generate or regenerate endpoints. See [installation](/docs/cli/overview/installation) to add it to a project, then the [commands](/docs/cli/commands) for everything it can do.
