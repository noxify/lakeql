description: Install the LakeQL CLI in your project.
---

Install `@lakeql/cli` as a development dependency — it is a build-time tool, not a runtime dependency:

<Command variant="install-dev">@lakeql/cli</Command>

This provides the `lakeql-cli` binary. Run it through your package manager:

<Command variant="exec">lakeql-cli init</Command>

If you scaffolded with [create-app](/docs/lakeql/create-app), the CLI is already installed and a `lakeql.config.ts` already exists.

<Note>
  The CLI reads `lakeql.config.ts` and connects to your data source, so it needs
  your environment set. Pass
  [`--env`](/docs/cli/configuration/environment-variables) to load an env file
  before the config is read.
</Note>
