The CLI commands fall into three kinds. **Project setup** (`init`, `add`) scaffolds and extends a project. **Introspection** (the `list-*` commands) explores a data source. **Generation** (`pull`, `create-endpoint`, `create-registry`, `generate-import-config`) writes the typed endpoint files.

Each command's arguments and options come from the CLI's own metadata, so they always match the installed version.

<Note>
  Every command accepts the global `--env [path]` option to load environment
  variables from a file before running (defaults to `.env` when given without a
  value).
</Note>
