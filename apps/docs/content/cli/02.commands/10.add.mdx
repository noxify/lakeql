---

`add` applies a named feature template to the current LakeQL project. A feature template adds the files and wiring for an integration, such as an authentication flow, into your existing project. You do not assemble the boilerplate by hand.

<Command variant="exec">lakeql-cli add fabric-obo</Command>

Preview the changes without writing anything with `--dry-run`:

<Command variant="exec">lakeql-cli add fabric-obo --dry-run</Command>
