`add` applies a named feature template to the current LakeQL project. A feature template adds the files and wiring for an integration — for example, an authentication flow — into your existing project, so you do not assemble the boilerplate by hand.

<Command variant="exec">lakeql-cli add fabric-obo</Command>

Preview the changes without writing anything using `--dry-run`:

<Command variant="exec">lakeql-cli add fabric-obo --dry-run</Command>
