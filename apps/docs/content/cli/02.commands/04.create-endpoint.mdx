---
title: create-endpoint
navTitle: create-endpoint
description: Create a custom endpoint from a JSON definition file.
cliCommand: create-endpoint
---

`create-endpoint` generates a typed endpoint from a JSON definition file instead of introspecting a live table. Use it to recreate an endpoint from a committed `endpoint.json`. Use it to define an endpoint by hand when you cannot reach the data source at generation time.

<Command variant="exec">
  lakeql-cli create-endpoint --from-file ./endpoint.json
</Command>

Each table that [`pull`](/docs/cli/commands/pull) generates includes an `endpoint.json` alongside its other files. That file is a valid input here, so endpoints are reproducible from the definition alone. The config registry is updated by default. Pass `--skip-registry` to skip it, or `--force` to overwrite existing files.

<Note>
  Unlike `pull` and `bulk-pull`, `create-endpoint` does not apply a data
  source's [`namePrefix`](/docs/lakeql/configuration/config-file#name-prefix).
  This is by design: `create-endpoint` builds from a manually authored
  definition with no live source config to read, whereas `pull` generates
  read-only schemas whose names it owns. See [Prefix
  scope](/docs/cli/configuration/config-file#prefix-scope) for the full
  rationale.
</Note>
