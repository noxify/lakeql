title: pull
navTitle: pull
description: Interactively generate a query endpoint from a remote table.
cliCommand: pull
---

`pull` introspects a remote table through its data source and generates the typed endpoint files for it — the interface, query schema, config, and JSON schema. Run interactively, it prompts for the source, catalog, schema, and table; pass those as options to skip the prompts.

<Command variant="exec">lakeql-cli pull</Command>

To run non-interactively, provide the target directly:

<Command variant="exec">
  lakeql-cli pull --source warehouse --catalog hive --schema sales --table
  orders
</Command>

Generated files are written under your configured source path, organized by data source, catalog, and schema. See [Key Concepts](/docs/lakeql/introduction/key-concepts) for the generated-file layout. For generating many endpoints at once, use `--bulk` with a bulk config.

<Warning>
  `pull` recreates the endpoint's output directory: it recursively deletes the
  target table's generated folder before writing. Do not keep hand-edited files
  inside a generated endpoint directory — put customizations in your own
  modules.
</Warning>

<Note>
  `pull` updates the config registry by default so new endpoints are type-safe.
  Pass `--skip-registry` to skip that step, then run
  [`create-registry`](/docs/cli/commands/create-registry) later.
</Note>
