`generate-import-config` writes an `import.config.mjs` from the schemas already generated under your source path. This file is a **bulk-pull config** for the CLI. It enumerates the generated endpoints so [`pull --bulk`](/docs/cli/commands/pull) can regenerate them in one run. The API server does not read it. The server discovers schemas by globbing the generated `query-schema`/`mutation-schema` files under its schema path.

<Command variant="exec">lakeql-cli generate-import-config</Command>

Run this after [`pull`](/docs/cli/commands/pull) has generated one or more endpoints. The file is written as `import.config.mjs` in the directory you run the command from. Use `--output` to write elsewhere, or `--force` to overwrite an existing file.
