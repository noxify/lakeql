---
title: Special Characters
description: Replaces special characters (umlauts, ligatures) in column names with ASCII equivalents.
---

`replaceSpecialCharacters` converts non-ASCII characters in field and column names to their ASCII equivalents. This is necessary when Trino column names contain German umlauts or other special characters that aren't valid in TypeScript identifiers or GraphQL field names.

## Usage

```typescript
import replaceSpecialCharacters from "@lakeql/helpers/special-characters"

replaceSpecialCharacters("größe") // "groesse"
replaceSpecialCharacters("straße") // "strasse"
replaceSpecialCharacters("Ärger") // "AErger"
replaceSpecialCharacters("Übung") // "UEbung"
```

## Default replacements

The built-in replacement list handles common German and European characters:

| Character(s) | Replacement | Examples         |
| ------------ | ----------- | ---------------- |
| Ä, Æ         | AE          | Ärger → AErger   |
| Ö, Œ         | OE          | Öl → OEl         |
| Ü            | UE          | Über → UEber     |
| ä, æ         | ae          | wählen → waehlen |
| ö, œ         | oe          | schön → schoen   |
| ü            | ue          | grün → gruen     |
| ß            | ss          | Straße → Strasse |

## Custom replacement list

You can provide a custom replacement list to handle additional characters:

```typescript
import replaceSpecialCharacters, {
  defaultReplaceList,
} from "@lakeql/helpers/special-characters"

const customList = [
  ...defaultReplaceList,
  { searchFor: /[éèê]/gu, replaceWith: "e" },
  { searchFor: /[àâ]/gu, replaceWith: "a" },
]

replaceSpecialCharacters("café", customList) // "cafe"
```
