---
title: formatCode
description: Formats TypeScript source code using Prettier with import sorting via @ianvs/prettier-plugin-sort-imports.
---

`formatCode` formats a TypeScript source string using Prettier with a preconfigured ruleset. It includes the `@ianvs/prettier-plugin-sort-imports` plugin to automatically organize import statements.

## Usage

```typescript
import formatCode from "@lakeql/helpers/format-code"

const raw = `import {swap} from "./object-helper"\nimport ts from "typescript"\nexport const x = 1`
const formatted = await formatCode(raw)
```

## Configuration

The formatter uses a fixed Prettier configuration:

| Option          | Value          |
| --------------- | -------------- |
| `printWidth`    | 100            |
| `tabWidth`      | 2              |
| `useTabs`       | false          |
| `semi`          | false          |
| `trailingComma` | `"es5"`        |
| `arrowParens`   | `"always"`     |
| `endOfLine`     | `"lf"`         |
| `parser`        | `"typescript"` |

## Import sorting

Imports are sorted into groups using `@ianvs/prettier-plugin-sort-imports`:

1. Type imports
2. React/Next.js imports
3. Third-party modules
4. `@lakeql/*` packages (with types first)
5. Local imports (`~/`, `@/`, relative paths)

## Error handling

If Prettier fails to format the code (e.g., due to syntax errors in the input), the function logs an error to console and returns the original unformatted value as a fallback.

```typescript
const result = await formatCode(invalidCode)
// Returns invalidCode unchanged if formatting fails
```
