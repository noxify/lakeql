---
title: calculatePageInfo
description: Computes pagination metadata from total count, page size, and current page number.
---

`calculatePageInfo` computes all pagination metadata needed for GraphQL Connection responses. It takes the total row count from Trino and the current page parameters, and returns navigation state, limits, and offsets.

## Usage

```typescript
import { calculatePageInfo } from "@lakeql/helpers/calculate-page-info"

const pageInfo = calculatePageInfo({
  totalCount: 95,
  perPage: 10,
  page: 3,
})

// {
//   currentPage: 3,
//   hasNext: true,
//   hasPrevious: true,
//   limit: 10,
//   maxPages: 10,
//   nextPage: 4,
//   previousPage: 2,
//   offset: 20,
//   totalCount: 95,
// }
```

## Parameters

| Parameter    | Type     | Required | Description                      |
| ------------ | -------- | -------- | -------------------------------- |
| `totalCount` | `number` | Yes      | Total number of records          |
| `perPage`    | `number` | Yes      | Number of records per page       |
| `page`       | `number` | No       | Current page number (default: 1) |

## Return value

| Field          | Type             | Description                               |
| -------------- | ---------------- | ----------------------------------------- |
| `currentPage`  | `number`         | The resolved current page                 |
| `hasNext`      | `boolean`        | Whether a next page exists                |
| `hasPrevious`  | `boolean`        | Whether a previous page exists            |
| `limit`        | `number`         | SQL LIMIT value (equals `perPage`)        |
| `maxPages`     | `number`         | Total number of pages                     |
| `nextPage`     | `number \| null` | Next page number, or null if at end       |
| `previousPage` | `number \| null` | Previous page number, or null if at start |
| `offset`       | `number \| null` | SQL OFFSET value, or null for first page  |
| `totalCount`   | `number`         | Passed through from input                 |

## Edge cases

```typescript
// First page — no previous, offset is null
calculatePageInfo({ totalCount: 50, perPage: 10, page: 1 })
// { hasPrevious: false, previousPage: null, offset: null, ... }

// Last page — no next
calculatePageInfo({ totalCount: 50, perPage: 10, page: 5 })
// { hasNext: false, nextPage: null, ... }

// Default page is 1 when omitted
calculatePageInfo({ totalCount: 50, perPage: 10 })
// { currentPage: 1, ... }
```
