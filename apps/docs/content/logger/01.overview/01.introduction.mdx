`@lakeql/logger` provides two logging exports used throughout the LakeQL ecosystem:

- **Main logger** (`@lakeql/logger`) — A structured logger built on `loglayer` with a `winston` transport. Includes automatic sensitive data redaction, error serialization, and colorized development output.
- **Console logger** (`@lakeql/logger/console`) — Simple success/error message formatters using `kleur` for colorized CLI output with unicode symbols.

## Main logger

The primary export creates a `LogLayer` instance configured with winston, context/metadata fields, and a redaction plugin.

```typescript
import { createLogger } from "@lakeql/logger"

const logger = createLogger()

logger.info("Server started", { port: 4000 })
logger.withContext({ requestId: "abc-123" }).info("Processing request")
logger.error("Query failed", new Error("Connection timeout"))
```

## Console logger

The console export provides formatted terminal output with checkmarks and cross symbols for CLI tools.

```typescript
import { success, error } from "@lakeql/logger/console"

console.log(success("Generated 5 schema files"))
// ✔ Generated 5 schema files

console.log(error("Failed to connect to Trino"))
// ✖ Failed to connect to Trino
```

## Dependencies

| Library                      | Role                                  |
| ---------------------------- | ------------------------------------- |
| `loglayer`                   | Logging abstraction layer             |
| `winston`                    | Transport and formatting engine       |
| `@loglayer/plugin-redaction` | Sensitive data redaction              |
| `fast-redact`                | High-performance path-based redaction |
| `serialize-error`            | Error object serialization            |
| `kleur`                      | Terminal color formatting             |
