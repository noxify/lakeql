title: Query Schema Files
description: Reference for generateQuerySchema — produces Pothos query types with Connection patterns, filtering, and sorting.
---

The `generateQuerySchema` function produces a complete Pothos GraphQL query type file. The output includes a Connection response type, a `Where` input type for filtering, and resolver logic with pagination and sorting.

## Usage

```typescript
import { generateQuerySchema } from "@lakeql/file-generator/query-schema"
import { generateCode } from "@lakeql/file-generator"

const nodes = generateQuerySchema({
  models,
  queryName: "allUsers",
  filterFields: ["name", "email", "is_active"],
  filterTypes: { name: "string", email: "string", is_active: "boolean" },
  transformFields: { user_name: "userName" },
  dateTimeFields: ["created_at"],
})

const sourceFile = await generateCode({
  fileName: "query-schema.ts",
  nodes,
})
```

## Generated structure

The generated file includes:

1. **Object type** — Pothos object type representing a single row
2. **Connection type** — Wraps results with `edges`, `nodes`, and `pageInfo`
3. **Where input type** — Filter input with fields matching the table columns
4. **Query field** — Resolver that builds SQL, executes via Trino client, and transforms results

```typescript
// Simplified example of generated output
import { builder } from "../builder"

const UserObject = builder.objectRef<UserType>("User").implement({
  fields: (t) => ({
    id: t.exposeInt("id"),
    userName: t.exposeString("userName"),
    createdAt: t.exposeString("createdAt"),
  }),
})

const UserWhereInput = builder.inputType("UserWhere", {
  fields: (t) => ({
    name: t.string({ required: false }),
    email: t.string({ required: false }),
  }),
})

builder.queryField("allUsers", (t) =>
  t.field({
    type: UserConnection,
    args: {
      where: t.arg({ type: UserWhereInput }),
      page: t.arg.int(),
      perPage: t.arg.int(),
    },
    resolve: async (root, args, ctx) => {
      // Query building, execution, and transformation logic
    },
  })
)
```

## Parameters

| Parameter         | Type                     | Description                               |
| ----------------- | ------------------------ | ----------------------------------------- |
| `models`          | Model definitions        | Parsed column models from column-parser   |
| `queryName`       | `string`                 | GraphQL query field name                  |
| `filterFields`    | `string[]`               | Column names available for filtering      |
| `filterTypes`     | `Record<string, string>` | Type mapping for each filter field        |
| `transformFields` | `Record<string, string>` | DB column → GraphQL field name mapping    |
| `dateTimeFields`  | `string[]`               | Fields requiring date/time transformation |
