---
title: Config Files
description: Reference for generateConfig — generates TypeScript config files with catalog, schema, and table metadata.
---

The `generateConfig` function produces TypeScript source that exports configuration constants. These constants are used at runtime by the API for permission checks, query routing, and documentation metadata.

## Usage

```typescript
import { generateConfig } from "@lakeql/file-generator/config"
import { generateCode } from "@lakeql/file-generator"

const nodes = generateConfig({
  catalog: "hive",
  schema: "analytics",
  tableName: "users",
  queryName: "allUsers",
  mutationName: ["createUser"],
})

const sourceFile = await generateCode({
  fileName: "config.ts",
  nodes,
})
```

## Generated output

The generated file exports two constants:

```typescript
export const hiveConfig = {
  catalog: "hive",
  schema: "analytics",
  tableName: "users",
} as const

export const docsConfig = {
  query: true,
  mutation: true,
  queryName: "allUsers",
  mutationName: ["createUser"],
}
```

## Parameters

| Parameter      | Type       | Required | Description                                              |
| -------------- | ---------- | -------- | -------------------------------------------------------- |
| `catalog`      | `string`   | Yes      | Trino catalog name (e.g., `hive`, `iceberg`)             |
| `schema`       | `string`   | Yes      | Trino schema name                                        |
| `tableName`    | `string`   | Yes      | Table name in the schema                                 |
| `queryName`    | `string`   | Yes      | GraphQL query field name                                 |
| `mutationName` | `string[]` | No       | GraphQL mutation field names (omit for read-only tables) |

When `mutationName` is omitted, the `docsConfig.mutation` field is set to `false` and `docsConfig.mutationName` is `null`.
