---
title: Introduction
description: What @lakeql/file-generator provides and how it generates TypeScript files from Trino metadata.
---

`@lakeql/file-generator` programmatically generates TypeScript source files using the TypeScript compiler API. It produces config files, TypeScript interfaces, query schemas, and mutation schemas from Trino table metadata — all fully formatted with Prettier via `@lakeql/helpers/format-code`.

## Sub-modules

The package exposes multiple entry points via subpath exports:

| Export                                   | Purpose                                             |
| ---------------------------------------- | --------------------------------------------------- |
| `@lakeql/file-generator`                 | Core `generateCode` function                        |
| `@lakeql/file-generator/config`          | Config file generation (`hiveConfig`, `docsConfig`) |
| `@lakeql/file-generator/config-registry` | Registry of all generated configs                   |
| `@lakeql/file-generator/interface`       | TypeScript interface generation                     |
| `@lakeql/file-generator/query-schema`    | Pothos query type generation                        |
| `@lakeql/file-generator/mutation-schema` | Mutation schema generation                          |

## Core function

The `generateCode` function is the foundation. It takes an array of TypeScript AST nodes, prints them, formats the output with Prettier, and returns a `SourceFile` object.

```typescript
import { generateCode } from "@lakeql/file-generator"
import ts from "typescript"

const sourceFile = await generateCode({
  fileName: "user-config.ts",
  nodes: [
    /* TypeScript AST nodes */
  ],
})

// sourceFile.text contains the formatted TypeScript source code
console.log(sourceFile.text)
```

## How it connects

The file generator is used by the CLI during the `generate` command. The CLI:

1. Queries Trino for table metadata
2. Passes columns through `@lakeql/column-parser`
3. Feeds parsed types into the file generator sub-modules
4. Writes the generated files to the project's schema directory

Each sub-module produces AST nodes that are passed to `generateCode` for formatting and output.
