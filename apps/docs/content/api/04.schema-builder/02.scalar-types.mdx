---
title: Scalar Types
navTitle: Scalar Types
description: The scalar types LakeQL registers on the schema.
---

The builder registers these scalars in addition to GraphQL's built-ins (`Int`, `Float`, `String`, `Boolean`, `ID`):

| Scalar     | Purpose                                                     |
| ---------- | ----------------------------------------------------------- |
| `Date`     | Calendar date, backed by `graphql-scalars`' `DateResolver`. |
| `DateTime` | Timestamp, backed by `graphql-scalars`' `DateTimeResolver`. |
| `File`     | Upload input scalar — usable only as an input type.         |

Generated interfaces map column types to these scalars so the GraphQL types match the underlying table. Date and timestamp columns surface as `Date` / `DateTime`, giving clients proper typing instead of raw strings.

<Note>
  `File` serializes only as input. Using it as an output type throws — it exists
  for upload arguments, not for returning file contents.
</Note>
