The schema is built with [Pothos](https://pothos-graphql.dev). LakeQL configures a shared `builder` with the scope-auth and validation plugins, registers the scalar and comparison types, and defines the pagination types. The generated query schema files attach to this builder, so every endpoint shares one consistent schema.

The pages below cover the builder configuration, the scalar and comparison types, pagination, and input validation.
