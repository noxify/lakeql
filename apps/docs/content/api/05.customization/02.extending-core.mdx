---
title: Extending Core
navTitle: Extending Core
description: Augment the generated types with additional fields.
---

Generated object types are defined on the shared [`builder`](/docs/api/api-reference#builder), so you can extend them rather than only adding standalone fields. Use the builder's object-field extension to add computed or related fields to a generated type.

```ts
import { builder } from "@lakeql/api/builder"

// Add a computed field to a generated `Order` type
builder.objectField(OrderRef, "displayName", (t) =>
  t.string({
    resolve: (order) => `#${order.id} — ${order.status}`,
  })
)
```

Extended fields participate in the same schema as the generated ones: they share the scope-auth scopes, the scalars, and the validation plugin. Keep extensions additive — the generated types are regenerated when a table changes, so put your additions in your own modules rather than editing generated files.

For entirely new root fields rather than extensions of existing types, see [custom queries and mutations](/docs/api/customization/custom-queries-mutations).
