## After Scaffolding

Once `@lakeql/create-app` finishes, follow these steps to get your API running.

<Stepper>
<StepperItem title="Configure environment">

Copy the example env file and fill in your Trino connection details:

```bash
cd my-api
cp .env.example .env
```

Edit `.env`:

```bash
HIVE_HOST="http://localhost"
HIVE_PORT=8080
HIVE_CATALOG=hive
HIVE_USERNAME="trino"
HIVE_PASSWORD="your-password"

AUTH_MOCK=true
AUTH_MOCK_TOKEN="dev-token"

API_PORT=4000
API_LOGGER="info"
```

</StepperItem>
<StepperItem title="Pull schemas from Trino">

Generate TypeScript files from your Trino tables:

<Command variant="run">cli pull --catalog hive --schema myschema</Command>

This creates:

- `src/schemas/generated/hive/myschema/<table>/config.ts` — Table metadata
- `src/schemas/generated/hive/myschema/<table>/interface.ts` — TypeScript interface
- `src/schemas/generated/hive/myschema/<table>/query-schema.ts` — GraphQL query schema
- `src/schemas/generated/hive/myschema/<table>/mutation-schema.ts` — GraphQL mutation schema
- `src/schemas/generated/hive/myschema/<table>/json-schema.json` — Response schema
- `src/schemas/generated/hive/myschema/<table>/endpoint.json` — Endpoint definition
- `src/config-registry.ts` — Aggregated config index

To pull multiple tables at once, pass `--table` multiple times:

<Command variant="run">
  cli pull --catalog hive --schema sales --table orders --table customers
  --table products
</Command>

</StepperItem>
<StepperItem title="Start the development server">

Launch the development server:

<Command variant="run">dev</Command>

You should see:

```
* Server URL: http://localhost:4000/
* GraphQL Endpoint: http://localhost:4000/graphql
```

</StepperItem>
<StepperItem title="Open GraphiQL">

Navigate to [http://localhost:4000/graphql](http://localhost:4000/graphql) in your browser.

Set the authorization header in GraphiQL's headers panel:

```json
{
  "Authorization": "dev-token"
}
```

Run a test query:

```graphql
query {
  __schema {
    queryType {
      fields {
        name
      }
    }
  }
}
```

This returns all available query fields — one for each table you pulled.

</StepperItem>
</Stepper>

## Common Next Steps

### Pull additional schemas

As you add tables to your lakehouse, pull them into the project:

<Command variant="run">cli pull --catalog hive --schema new_schema</Command>

### Configure permissions

Set up user-level read/write permissions for production. See [Authentication](/docs/lakeql/configuration/authentication).

## Troubleshooting

| Issue | Solution |
| --- | --- |
| `pull` fails with connection error | Verify `HIVE_HOST` and `HIVE_PORT` in `.env`. Check Trino is running. |
| Server starts but no queries available | Run `pnpm cli pull` first. Check that `schemaPath` points to the correct directory. |
| Auth errors in GraphiQL | Set `AUTH_MOCK=true` and include the `Authorization` header matching `AUTH_MOCK_TOKEN`. |
| Generated types have wrong fields | Re-run `pull` to sync with current Trino table structure. |
