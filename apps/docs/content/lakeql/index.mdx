LakeQL generates a type-safe GraphQL API over your data lakehouse. Point it at a Trino or Microsoft Fabric data source, generate typed endpoints from your real tables, and serve them through a GraphQL server you compose from explicit, well-separated building blocks.

New here? Start with the [introduction](/docs/lakeql/introduction) for the core concepts, then the [getting started](/docs/lakeql/getting-started) guide to scaffold a project and make your first request.
