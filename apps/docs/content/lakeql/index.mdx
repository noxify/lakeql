LakeQL is a universal data access layer for modern platforms. It generates a type-safe GraphQL API across your data stack, served through a GraphQL server you compose from explicit building blocks. Point it at a data source, generate typed endpoints from your real tables, and query them. Adapters for Trino and Microsoft Fabric are available today. ClickHouse and DuckDB are on the roadmap.

New here? Read the [introduction](/docs/lakeql/introduction) for the core concepts. Then follow the [getting started](/docs/lakeql/getting-started) guide to scaffold a project and make your first request.
