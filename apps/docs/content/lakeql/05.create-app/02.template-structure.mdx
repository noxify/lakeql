create-app generates a complete, runnable project. The exact files depend on the adapters and authentication strategy you choose, but the shape is consistent:

## How the Pieces Connect

- **`lakeql.config.ts`** declares the adapters and data sources. See [config file](/docs/lakeql/configuration/config-file).
- **`src/index.ts`** loads the config, composes the runtime, and starts the API server. See [server setup](/docs/api/server-setup).
- **`src/auth.ts`** / **`src/permissions.ts`** wire [authentication](/docs/api/authentication) and [permissions](/docs/api/authentication/permissions).
- **`src/schemas/`** is where [`pull`](/docs/cli/commands/pull) writes generated endpoint files.

The generated project uses `workspace:*` dependency versions only in local dev mode (`--local`); a normal run pins published versions.
