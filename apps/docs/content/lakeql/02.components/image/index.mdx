## Markdown syntax

Die Modi lassen sich auch direkt ueber das normale Markdown-Image-Tag setzen,
indem im optionalen Title-Teil Optionen uebergeben werden.

| Variante                   | Beispiel                                                                       | Ergebnis                       |
| -------------------------- | ------------------------------------------------------------------------------ | ------------------------------ |
| Title-Optionen (empfohlen) | `![Zoom](https://picsum.photos/id/1016/2400/1400 "mode=zoom fit=cover")`       | Zoom-Preview mit cover         |
| Alt-Text-Hinweis           | `![Docs image mode=zoom fit=contain](https://picsum.photos/id/1016/2400/1400)` | Zoom-Preview mit contain       |
| URL-Fragment               | `![Zoom](https://picsum.photos/id/1016/2400/1400#mode=zoom&fit=cover)`         | Zoom-Preview mit cover         |
| Legacy Alias               | `![Preview](https://picsum.photos/id/1016/2400/1400 "mode=preview")`           | wird wie `mode=zoom` behandelt |

```mdx
![Default](https://picsum.photos/id/1018/1800/1100 "mode=default")
![Zoom](https://picsum.photos/id/1016/2400/1400 "mode=zoom fit=cover")
![Docs image mode=zoom fit=contain](https://picsum.photos/id/1016/2400/1400)
![Zoom](https://picsum.photos/id/1016/2400/1400#mode=zoom&fit=cover)
```

Hinweis: `mode=preview` wird weiterhin als Alias fuer `mode=zoom` akzeptiert.
