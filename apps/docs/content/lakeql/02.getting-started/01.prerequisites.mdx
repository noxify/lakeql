Before you begin, make sure you have:

- **Node.js** — a current LTS release (Node 24 or newer is recommended; the generated project targets modern Node).
- **A package manager** — npm, pnpm, or yarn.
- **A reachable data source** — a Trino coordinator or a Microsoft Fabric SQL endpoint you can connect to, with credentials.

You do not need to install any LakeQL package globally. The quickstart scaffolds a project with everything wired in, and the CLI runs through your package manager.

Next: scaffold a project in the [quickstart](/docs/lakeql/getting-started/quickstart).
