## Create Your First LakeQL API

Get a GraphQL API running over your Trino lakehouse in five steps.

<Stepper>
<StepperItem title="Scaffold a new project">

Use `create-lakeql-app` to bootstrap a new project with all dependencies pre-configured:

```bash
npx create-lakeql-app my-api
```

Follow the interactive prompts to select your package manager and install dependencies.

</StepperItem>
<StepperItem title="Configure environment variables">

Navigate into your project and create a `.env` file from the template:

```bash
cd my-api
cp .env.example .env
```

Edit `.env` with your Trino connection details:

```bash
HIVE_HOST="http://localhost"
HIVE_PORT=8080
HIVE_CATALOG=hive
HIVE_USERNAME="trino"
HIVE_PASSWORD="your-password"

AUTH_MOCK=true
AUTH_MOCK_TOKEN="dev-token"

API_PORT=4000
API_LOGGER="info"
```

</StepperItem>
<StepperItem title="Pull schema from Trino">

Generate TypeScript schemas from your Trino tables:

```bash
npx lakeql-cli pull --catalog hive --schema myschema --target ./src
```

This introspects all tables in `hive.myschema` and generates typed config, interface, and query-schema files.

</StepperItem>
<StepperItem title="Start the API server">

Launch the GraphQL server:

```bash
npx tsx src/server.ts
```

You should see output like:

```
* Server URL: http://localhost:4000/
* GraphQL Endpoint: http://localhost:4000/graphql
```

</StepperItem>
<StepperItem title="Run your first query">

Open [http://localhost:4000/graphql](http://localhost:4000/graphql) in your browser to access GraphiQL.

Run a query against one of your generated schemas:

```graphql
query {
  users(paging: { limit: 5 }) {
    totalCount
    pageInfo {
      hasNext
      currentPage
      maxPages
    }
    nodes {
      id
      name
      email
    }
  }
}
```

Include the authorization header:

```json
{
  "Authorization": "dev-token"
}
```

</StepperItem>
</Stepper>
