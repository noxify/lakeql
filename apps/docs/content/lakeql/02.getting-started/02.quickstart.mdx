The fastest way to a working project is the scaffolding tool. It creates the config, the server entry point, and the project structure for you.

<Command variant="create">@lakeql/app my-api</Command>

It prompts for the adapters, data source names, and authentication strategy, then generates the project. See [create-app](/docs/lakeql/create-app) for the full list of options and what gets generated.

## Next Steps

<Steps>

<Step>Configure the environment</Step>

Fill in your data source connection details. See [environment configuration](/docs/lakeql/getting-started/environment-configuration).

<Step>Generate an endpoint</Step>

Introspect a table and generate its typed files with [`pull`](/docs/cli/commands/pull).

<Step>Start the server</Step>

Run the server and make your [first request](/docs/lakeql/getting-started/first-run).

</Steps>
