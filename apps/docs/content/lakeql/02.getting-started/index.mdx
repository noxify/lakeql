Go from nothing to a running GraphQL API: check the [prerequisites](/docs/lakeql/getting-started/prerequisites), scaffold a project in the [quickstart](/docs/lakeql/getting-started/quickstart), [configure the environment](/docs/lakeql/getting-started/environment-configuration), and make your [first request](/docs/lakeql/getting-started/first-run).

If you already know the pieces, the short version is: scaffold with [create-app](/docs/lakeql/create-app), point `lakeql.config.ts` at your data source, generate an endpoint with [`pull`](/docs/cli/commands/pull), and start the server.
