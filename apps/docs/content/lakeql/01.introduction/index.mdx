LakeQL generates a type-safe GraphQL API over your data lakehouse. Instead of hand-writing resolvers for every table, you introspect your data source, generate typed schema files, and serve them through a GraphQL server you compose from explicit building blocks.

This section establishes the vocabulary the rest of the documentation builds on.
