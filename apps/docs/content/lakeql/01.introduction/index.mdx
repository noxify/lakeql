LakeQL is a universal data access layer for modern platforms. It generates a type-safe GraphQL API across your data stack. You introspect your data source, generate typed schema files, and serve them through a GraphQL server you compose from explicit building blocks. No hand-written resolvers per table.

This section sets the vocabulary the rest of the documentation builds on.
