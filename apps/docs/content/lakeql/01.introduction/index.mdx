LakeQL generates a type-safe GraphQL API over your data lakehouse. You introspect your data source, generate typed schema files, and serve them through a GraphQL server you compose from explicit building blocks. No hand-written resolvers per table.

This section sets the vocabulary the rest of the documentation builds on.
