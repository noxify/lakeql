A LakeQL project is configured through `lakeql.config.ts` and the environment. This section covers the [config file](/docs/lakeql/configuration/config-file) structure, the [runtime lifecycle](/docs/lakeql/configuration/runtime-lifecycle) that composes it into live data sources, and the [environment variables](/docs/lakeql/configuration/environment-variables) that feed it.

The configuration API lives in [`@lakeql/config`](/docs/packages/config) — this section is the project-author view of it.
