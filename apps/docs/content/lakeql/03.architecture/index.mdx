This section walks through the [system overview](/docs/lakeql/architecture/system-overview), how [data flows](/docs/lakeql/architecture/data-flow) from a GraphQL query to SQL and back, and the [lifecycle of a single request](/docs/lakeql/architecture/request-lifecycle).
