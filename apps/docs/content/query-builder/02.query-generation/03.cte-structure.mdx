title: CTE Structure
description: The two-CTE query pattern used for pagination metadata and record retrieval.

## Overview

Every query generated by the query builder uses a Common Table Expression (CTE) pattern with two named subqueries: `total_count` and `records`. These are joined together in the final SELECT to return both pagination metadata and actual data rows in a single round-trip.

## total_count CTE

The first CTE computes the total number of rows matching the filter criteria. It applies the same `WHERE` clause as the records CTE but only performs a `COUNT(*)`.

```sql
WITH total_count AS (
  SELECT COUNT(*) AS "total_records"
  FROM "hive"."sales"."orders"
  WHERE "status" = 'shipped'
)
```

This value powers the `totalCount` field in GraphQL connection responses, allowing clients to calculate total pages without a separate query.

## records CTE

The second CTE selects the actual data rows with the full SELECT list, WHERE clause, ORDER BY, and FETCH/OFFSET pagination.

```sql
records AS (
  SELECT "id", "customer_name", to_unixtime(created_at) AS "created_at"
  FROM "hive"."sales"."orders"
  WHERE "status" = 'shipped'
  ORDER BY "created_at" DESC
  FETCH FIRST 25 ROWS ONLY
)
```

## Final Join

The two CTEs are combined with a `FULL JOIN ... ON TRUE` to produce a single result set containing both the total count and the page of records:

```sql
SELECT *
FROM total_count
FULL JOIN records ON TRUE
```

Each result row includes the `total_records` column alongside the selected data fields. The GraphQL resolver reads `total_records` from the first row for pagination info and maps the remaining columns into response nodes.

## Complete Example

```sql
WITH total_count AS (
  SELECT COUNT(*) AS "total_records"
  FROM "hive"."sales"."orders"
  WHERE "status" = 'shipped'
),
records AS (
  SELECT "id", "customer_name", to_unixtime(created_at) AS "created_at"
  FROM "hive"."sales"."orders"
  WHERE "status" = 'shipped'
  ORDER BY "created_at" DESC
  FETCH FIRST 25 ROWS ONLY
)
SELECT *
FROM total_count
FULL JOIN records ON TRUE
```
