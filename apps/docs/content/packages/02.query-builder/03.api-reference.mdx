The complete public API of `@lakeql/query-builder`, generated from the package's TypeScript source.

The main entry point is [`generateQuery`](#generate-query). It turns selected fields, a filter, sorting, and paging into a compiled SQL query. The filter types ([`Where`](#where), [`Field`](#field), [`FieldOptions`](#field-options)) describe the shape of a filter. The helper functions ([`getSelectFields`](#get-select-fields), [`normalizeFilter`](#normalize-filter), [`formatQuery`](#format-query)) build and inspect queries.
