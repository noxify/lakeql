The complete public API of `@lakeql/config`, generated from the package's TypeScript source.

The three functions you use most are [`defineConfig`](#define-config) (author the config file), [`loadConfig`](#load-config) (load and validate it), and [`createLakeQLRuntime`](#create-lake-ql-runtime) (compose the runtime that owns your data sources). The remaining exports are the config and runtime types, the [`AdapterRegistry`](#adapter-registry), the [`RuntimeLifecycleManager`](#runtime-lifecycle-manager), and the error classes thrown during loading and runtime construction.
