Create a client by constructing [`FabricClient`](/docs/packages/fabric-client/api-reference#fabric-client) with the endpoint, catalog, and authentication.

```ts
import { FabricClient } from "@lakeql/fabric-client"

const client = new FabricClient({
  host: "your-endpoint.datawarehouse.fabric.microsoft.com",
  port: 1433,
  catalog: "my_warehouse",
  auth: {
    type: "oauth2",
    tenantId: "...",
    clientId: "...",
    clientSecret: "...",
  },
})
```

## Authentication

Two auth types are supported, both resolving to an Azure AD access token:

```ts
// OAuth2 client credentials
auth: { type: "oauth2", tenantId: "...", clientId: "...", clientSecret: "..." }

// Static bearer token
auth: { type: "bearer", token: "..." }
```

The `oauth2` form accepts an optional `scope` field, but it currently has no effect — the token is always acquired for the Fabric SQL scope (`https://database.windows.net/.default`).

## Retry

The constructor takes an optional second argument, a [`RetryConfig`](/docs/packages/fabric-client/api-reference#retry-config), applied to each query:

```ts
const client = new FabricClient(props, { maxRetries: 3 })
```

## Connection Lifecycle

The client manages a TDS connection pool internally. Call [`close`](/docs/packages/fabric-client/api-reference#fabric-client-close) to release it when you are done:

```ts
await client.close()
```

A closed client throws `FabricClientError` if used again.
