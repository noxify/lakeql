The complete public API of `@lakeql/fabric-client`, generated from the package's TypeScript source.

The entry point is the [`FabricClient`](#fabric-client) class, which executes T-SQL queries against a Microsoft Fabric SQL endpoint. Authentication is handled through [`resolveCredential`](#resolve-credential) and the [`FabricAuth`](#fabric-auth) type; [`withRetry`](#with-retry) wraps calls with configurable retry. The remaining exports are the configuration types and the error classes.
