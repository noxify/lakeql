## Capabilities

| Capability                 | Support                |
| -------------------------- | ---------------------- |
| Reads                      | Yes                    |
| Writes                     | No — read-only adapter |
| DDL (create / drop tables) | No                     |
| Metadata introspection     | Yes                    |

For writes, see the Trino adapter and [Writing](/docs/data-sources/writing). For metadata introspection, see [Metadata](/docs/data-sources/fabric/metadata).

`@lakeql/adapter-fabric` connects LakeQL to a Microsoft Fabric SQL endpoint. It implements the datasource contract over TDS (via the standalone [fabric-client](/docs/packages/fabric-client)), provides the T-SQL dialect, and authenticates with Azure AD.

Register it in your config:

```ts
import { defineConfig } from "@lakeql/config"
import { fabricAdapterDefinition } from "@lakeql/adapter-fabric"

export default defineConfig({
  adapters: [fabricAdapterDefinition],
  dataSources: {
    reporting: {
      adapter: "fabric",
      connection: {
        host: "your-endpoint.datawarehouse.fabric.microsoft.com",
        port: 1433,
        catalog: "my_warehouse",
        auth: {
          type: "oauth2",
          tenantId: "...",
          clientId: "...",
          clientSecret: "...",
        },
      },
    },
  },
})
```

This section covers the [connection](/docs/data-sources/fabric/connection) and [metadata](/docs/data-sources/fabric/metadata), with the full [API reference](/docs/data-sources/fabric/api-reference) at the end. For how a read executes end to end, see [data flow](/docs/lakeql/architecture/data-flow).
