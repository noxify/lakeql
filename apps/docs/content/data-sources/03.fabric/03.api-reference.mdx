The complete public API of `@lakeql/adapter-fabric`, generated from the package's TypeScript source.

You register the adapter with [`fabricAdapterDefinition`](#fabric-adapter-definition) in your config. The rest of the surface is the connection config ([`FabricConnectionConfig`](#fabric-connection-config), [`FabricAuth`](#fabric-auth)), the SQL dialect, the response normalizer, and the type mapper that the runtime wires together.
