`@lakeql/adapter-fabric` connects LakeQL to a Microsoft Fabric SQL endpoint. It implements the datasource contract over TDS (via the standalone [fabric-client](/docs/packages/fabric-client)), provides the T-SQL dialect, and authenticates with Azure AD.

Register it in your config:

```ts
import { defineConfig } from "@lakeql/config"
import { fabricAdapterDefinition } from "@lakeql/adapter-fabric"

export default defineConfig({
  adapters: [fabricAdapterDefinition],
  dataSources: {
    reporting: {
      adapter: "fabric",
      connection: {
        host: "your-endpoint.datawarehouse.fabric.microsoft.com",
        port: 1433,
        catalog: "my_warehouse",
        auth: {
          type: "oauth2",
          tenantId: "...",
          clientId: "...",
          clientSecret: "...",
        },
      },
    },
  },
})
```

This section covers the [connection](/docs/data-sources/fabric/connection) and [queries](/docs/data-sources/fabric/queries), with the full [API reference](/docs/data-sources/fabric/api-reference) at the end.
