`@lakeql/adapter-trino` connects LakeQL to a Trino coordinator. It implements the datasource contract over the Trino REST API, provides the Trino SQL dialect, and offers two write strategies (external storage and `INSERT INTO`).

Register it in your config:

```ts
import { defineConfig } from "@lakeql/config"
import { trinoAdapterDefinition } from "@lakeql/adapter-trino"

export default defineConfig({
  adapters: [trinoAdapterDefinition],
  dataSources: {
    warehouse: {
      adapter: "trino",
      connection: {
        host: "https://trino.example.com",
        port: 8080,
        catalog: "hive",
        auth: { type: "basic", username: "svc", password: "..." },
      },
    },
  },
})
```
