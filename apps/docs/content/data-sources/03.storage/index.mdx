Storage operations back the [external-storage write strategy](/docs/data-sources/writing). They encapsulate the interaction with object storage (S3, MinIO, GCS, Azure, and the like) — uploading, listing, and deleting files — without knowing anything about load strategies.

This section covers the [storage operations](/docs/data-sources/storage/storage-operations) the write pipeline relies on.
