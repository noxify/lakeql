## Capabilities

| Capability                 | Support                                      |
| -------------------------- | -------------------------------------------- |
| Reads                      | Yes                                          |
| Writes                     | Yes — INSERT and external-storage strategies |
| DDL (create / drop tables) | Yes                                          |
| Metadata introspection     | Yes                                          |

For how writing works across adapters, see [Writing](/docs/data-sources/writing).

`@lakeql/adapter-trino` connects LakeQL to a Trino coordinator. It implements the datasource contract over the Trino REST API and provides the Trino SQL dialect.

Register it in your config:

```ts
import { defineConfig } from "@lakeql/config"
import { trinoAdapterDefinition } from "@lakeql/adapter-trino"

export default defineConfig({
  adapters: [trinoAdapterDefinition],
  dataSources: {
    warehouse: {
      adapter: "trino",
      connection: {
        host: "https://trino.example.com",
        port: 8080,
        catalog: "hive",
        auth: { type: "basic", username: "svc", password: "..." },
      },
    },
  },
})
```
