A data source is how LakeQL reaches a query engine. An adapter implements a neutral contract so the core packages — the API, the CLI, the query builder — never depend on a specific engine.

This section introduces [what data sources and adapters are](/docs/data-sources/overview/introduction) and the [datasource contract](/docs/data-sources/overview/datasource-contract) that adapters implement, with the [`@lakeql/datasource` API reference](/docs/data-sources/overview/api-reference) at the end.
