# @lakeql/response-transformer

Transforms raw Trino query responses into typed objects based on JSON Schema definitions, with support for date conversion and field renaming.

## Installation

```bash
pnpm add @lakeql/response-transformer
```

## Documentation

See the [LakeQL Documentation](https://lakeql.dev/docs) for detailed usage instructions.
