# @lakeql/scaffold

Consumer-neutral scaffolding engine for LakeQL: the declarative `Op`/`Plan` model, the TypeScript value serializer, plan→string builders, and greenfield file materialization.

## Installation

```bash
pnpm add @lakeql/scaffold
```

## Documentation

See the [LakeQL Documentation](https://lakeql.dev/docs) for detailed usage instructions.
