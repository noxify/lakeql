# @lakeql/query-builder

SQL query builder for Trino using Kysely, supporting dynamic filters (AND/OR), sorting, pagination, and field transformations.

## Installation

```bash
pnpm add @lakeql/query-builder
```

## Documentation

See the [LakeQL Documentation](https://lakeql.dev/docs) for detailed usage instructions.
