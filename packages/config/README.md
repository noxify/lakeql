# @lakeql/config

Adapter-factory registry and composition layer for LakeQL runtimes: resolves and wires data-source adapters from a project's configuration.

## Installation

```bash
pnpm add @lakeql/config
```

## Documentation

See the [LakeQL Documentation](https://lakeql.dev/docs) for detailed usage instructions.
