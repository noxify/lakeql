# @lakeql/file-generator

Generates TypeScript source files (configs, interfaces, query schemas) from parsed table models using the TypeScript Compiler API.

## Installation

```bash
pnpm add @lakeql/file-generator
```

## Documentation

See the [LakeQL Documentation](https://lakeql.dev/docs) for detailed usage instructions.
