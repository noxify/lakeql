# @lakeql/adapter-trino

Trino adapter for LakeQL: connects the adapter-neutral LakeQL runtime to a Trino coordinator for reads and writes.

## Installation

```bash
pnpm add @lakeql/adapter-trino
```

## Documentation

See the [LakeQL Documentation](https://lakeql.dev/docs) for detailed usage instructions.
