# @lakeql/datasource

Adapter-neutral contracts for LakeQL data sources: the read-strategy, write-strategy, and adapter-factory interfaces every adapter implements.

## Installation

```bash
pnpm add @lakeql/datasource
```

## Documentation

See the [LakeQL Documentation](https://lakeql.dev/docs) for detailed usage instructions.
