# @lakeql/adapters

Storage adapters for LakeQL — provides S3 storage operations, Hive table management, and the write pipeline orchestrator for mutation resolvers.

## Installation

```bash
pnpm add @lakeql/adapters
```

## Documentation

See the [LakeQL Documentation](https://lakeql.dev/docs) for detailed usage instructions.
