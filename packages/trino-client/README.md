# @lakeql/trino-client

HTTP client for the Trino REST API with support for paginated queries, streaming, and catalog metadata introspection.

## Installation

```bash
pnpm add @lakeql/trino-client
```

## Documentation

See the [LakeQL Documentation](https://lakeql.dev/docs) for detailed usage instructions.
