# @lakeql/fabric-client

TDS client for executing T-SQL queries on Microsoft Fabric SQL endpoints, used by the LakeQL Fabric adapter.

## Installation

```bash
pnpm add @lakeql/fabric-client
```

## Documentation

See the [LakeQL Documentation](https://lakeql.dev/docs) for detailed usage instructions.
