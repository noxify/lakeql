# @lakeql/parquet

JSON Schema to Parquet conversion and writing for LakeQL — converts JSON Schema definitions to hyparquet-compatible schemas and serializes records into Parquet binary format.

## Installation

```bash
pnpm add @lakeql/parquet
```

## Documentation

See the [LakeQL Documentation](https://lakeql.dev/docs) for detailed usage instructions.
