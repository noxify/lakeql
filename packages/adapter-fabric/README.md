# @lakeql/adapter-fabric

Microsoft Fabric adapter for LakeQL: connects the adapter-neutral LakeQL runtime to a Microsoft Fabric SQL endpoint for reads.

## Installation

```bash
pnpm add @lakeql/adapter-fabric
```

## Documentation

See the [LakeQL Documentation](https://lakeql.dev/docs) for detailed usage instructions.
