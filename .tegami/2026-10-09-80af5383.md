### Add the `@lakeql/scaffold` package

New package providing the consumer-neutral scaffolding primitives shared by `create-app` and the CLI:

- the Op/Plan model (`buildPlan`, `applyOp`) and the TypeScript value serializer (`serializeTs`, `expr`);
- the plan→string builders (`generateEnvExample`, `generateEnvTs`, `generateLakeqlConfig`) and the greenfield materializer (`materializeFiles`, `WriteMode`);
- `applyFeature`, which idempotently applies a feature into an existing project: it adds absent dependencies (sorted write-back), appends missing `.env.example` keys under their group heading, writes new files without clobbering user content, and returns `applied`/`guidance` so callers can print the `env.ts` and `lakeql.config.ts` edits to make by hand (a `--dry-run` mode previews without writing);
- the feature-template model (`FeatureTemplate`, `FeatureContext`, `FeatureResult`), the `featureRegistry`, and `resolveFeatureTemplate` (throws `UnknownFeatureError` with the available ids).

The package stays dependency-light: `@lakeql/config` is a type-only dev dependency, so the emitted runtime carries no config import.
