### App-builder sidebar shell and richer validation presentation

`@lakeql/studio` reorganizes the Endpoint Builder into a `sidebar-09`-style app-builder shell: an icon rail (General Settings, Fields, Validations, JSON) with a contextual secondary sidebar, a main content area, and a header bar. Import and Export move to the header as actions, with Export still gated on a valid definition. The field-type palette now lives in the Fields view's secondary sidebar beside the canvas, both sharing the single drag-and-drop context so palette-to-canvas drags and keyboard-add keep working.

Validation presentation is upgraded. Each field card shows an issue badge when it has a validation problem, and the badge clears live as the issue is fixed; selecting the field shows the readable details in its properties panel. A new Validations view consolidates every current issue into a readable list — fields named by their nesting context rather than raw schema paths — where activating an entry jumps to the Fields view, selects the offending field, and moves keyboard focus to it; metadata issues are listed but not clickable, and a "ready to export" state shows when there are none. The JSON view gains a copy-to-clipboard action, and the Fields view adds a single empty-state with add and import guidance plus a visible keyboard-move hint. The core, the canvas drag/keyboard logic, the validity gate, and the exported definition format are unchanged.
