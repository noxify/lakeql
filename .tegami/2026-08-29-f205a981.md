### trinoUserImpersonation: transform the claim value

`trinoUserImpersonation` accepts an optional `transform` to map the JWT claim to the Trino username before it is sent as `X-Trino-User`, for when the IdP claim does not match the Trino username verbatim. Pass `"lower"` or `"upper"` for case normalization, or a function for anything else (e.g. stripping a domain, `(v) => v.split("@")[0]`). A transform that yields an empty string falls back to no impersonation. The default behavior is unchanged.
