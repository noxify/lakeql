### Fix missing navigation on mobile viewports

The Endpoint Builder now stays navigable on phones. An always-visible trigger in the main header opens the primary rail (which is off-canvas on mobile), so the Settings / Fields / Validations / JSON views are reachable again. At phone widths the contextual secondary navigation (the field-type palette and the validation issue list) no longer occupies a fixed side column that clipped the main content — it collapses into an on-demand sheet opened from a second header trigger, giving the main content full width. Desktop and tablet layout is unchanged.
