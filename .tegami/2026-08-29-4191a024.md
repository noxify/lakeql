### Scope generated auth env vars to the chosen strategy

The generated project now only includes the environment variables for the selected authentication strategy: mock auth gets `AUTH_MOCK` and `AUTH_MOCK_TOKEN`, while Microsoft Entra ID gets `AUTH_TENANT_ID`. The Entra ID resolver no longer carries a mock-token fallback, so its `.env.example`, `src/env.ts`, and `src/auth.ts` stay consistent and focused on real JWT verification.
