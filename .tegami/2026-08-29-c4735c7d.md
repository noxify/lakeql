### Fix local-mode scaffolding inside a monorepo

Scaffolding with `--local` no longer breaks dependency installation. Previously the generated project got its own `pnpm-workspace.yaml`, which isolated it from the surrounding monorepo and made `pnpm install` fail to resolve the `workspace:*` packages. In local mode the generator now skips the isolated install and nested workspace file, leaving installation to the monorepo root, and the next-steps hint reflects that. Generated `package.json` dependencies are now written in alphabetical order so they pass monorepo consistency checks.
