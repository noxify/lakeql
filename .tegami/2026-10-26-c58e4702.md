### Share SQL rendering primitives from @lakeql/datasource

`@lakeql/datasource` now exports adapter-neutral SQL primitives: `escapeLiteral`, `rejectControlChars`, `isPlainObject`, and a parameterized `quoteQualified(quoteFn, ...segments)`. The Trino and Fabric adapters consume these instead of maintaining byte-identical copies; each adapter keeps its own dialect-specific `quoteIdentifier` (double-quote vs bracket doubling) and delegates qualified-identifier joining to the shared helper. Escaping and identifier-quoting semantics are unchanged.

### Strict plain-object detection in @lakeql/helpers

`isObject` from `@lakeql/helpers/object-helper` now uses a prototype-based plain-object check. It no longer throws on prototype-less objects created with `Object.create(null)` and still returns `false` for arrays, class instances, `Date`, `RegExp`, and other exotic objects.
