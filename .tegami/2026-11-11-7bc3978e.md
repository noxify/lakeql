### Command palette Add-field sub-view starts at the top and can be exited

In `@lakeql/studio`, opening the Endpoint Builder command palette's "Add field…" sub-view now highlights the first option ("Add String field") and scrolls the list to the top, so the group heading and first option are visible without scrolling up. The sub-view can also be left without closing the whole palette: pressing Escape returns to the main command list (Escape from the main list still closes the palette), and a "Back" entry offers the same path by click or keyboard.
