### Drop magic-regexp to shrink production installs

`@lakeql/schema-generator` no longer depends on `magic-regexp`. It was used in a single place to strip parameters off SQL type strings (for example `timestamp(3)` → `timestamp`), which is now done with a native regular expression.

Removing it cuts the `unplugin` chain at the source, so `esbuild` (~20 MB) and `@rolldown/binding` (~17 MB) — installed as `unplugin`'s optional peers — no longer land in the production dependency closure of scaffolded apps, substantially shrinking a standalone `pnpm i --prod` install.
