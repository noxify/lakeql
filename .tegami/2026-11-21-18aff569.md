### Desktop-only Endpoint Builder

The Endpoint Builder now supports desktop-width viewports only. Below 768px a "Desktop only" notice replaces the editor. The editor stays mounted underneath, so the draft, the current state and the undo history survive a temporary window resize. Pass `desktopOnly={false}` to `EndpointBuilder` to render the responsive mobile layout again.
