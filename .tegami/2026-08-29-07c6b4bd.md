### Surface the Trino message for access-denied errors

A failed Trino query previously reported only the error name and type (e.g. `Trino query failed: PERMISSION_DENIED (USER_ERROR)`), hiding what was actually denied. For access-control failures (`PERMISSION_DENIED`) the error now includes Trino's message, which names the denied action and object (e.g. `Access Denied: Cannot select from table catalog.schema.table`). Other error types keep just the name and type, since their messages can echo the submitted SQL.
