### Load `lakeql.config.ts` files that use relative imports in a standalone app

Loading a `lakeql.config.ts` that imports sibling modules with extensionless
relative specifiers (for example `import { env } from "./src/env"`) now works
in a freshly scaffolded app. Previously this failed with
`Failed to resolve config file` / `LAKEQL_CONFIG_LOAD_FAILED` because the
config loader relied on native `import()`, which cannot resolve extensionless
relative TypeScript imports. The loader now uses `jiti` (added as a direct
dependency) to resolve those specifiers deterministically.
