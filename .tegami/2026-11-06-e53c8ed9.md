### Progress spinners for remote lookups

Interactive CLI commands now show a progress spinner while they wait on remote data-source lookups that previously ran with no feedback. Catalog, schema, table, view, and column lookups that precede a prompt each display a labelled spinner ("Loading catalogs…", "Loading schemas…", "Loading tables…", "Loading views…", "Loading columns…") so slower round-trips no longer look like the CLI has stalled.

This covers `pull`, `bulk-pull`, and every `list-*` command. The spinner appears immediately and clears before each prompt renders. On non-interactive runs (piped output or CI) no animation is emitted and behavior is unchanged.
