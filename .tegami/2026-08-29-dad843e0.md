### Add a Custom authentication strategy

`create-lakeql-app` now offers a "Custom" authentication strategy (`--auth custom`) that scaffolds a typed, documented `TokenResolver` boilerplate for you to implement your own authentication (e.g. Auth0, Keycloak, API keys). It adds no auth-specific environment variables or dependencies, leaving the implementation entirely up to you.
