### Fix create-app auth generator and add metadata subpath export

The generated `auth.ts` now imports `TokenResolver` from `@lakeql/config` instead of the non-existent `@lakeql/api/types` path, for both the mock and Entra ID strategies. `@lakeql/create-app` also exposes a new `./metadata` subpath export so documentation tooling can read command metadata via `getCreateAppCommandConfig()`, and the package `types` entry now points at the emitted `.d.mts` declaration.

### Expose option choices in CLI command metadata

`CommandOptionMeta` from `@lakeql/cli` now includes an optional `choices` field, populated from an option's allowed values. This lets consumers render the accepted values for options that constrain their input.
