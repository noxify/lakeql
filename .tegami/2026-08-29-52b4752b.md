### Clearer `lakeql add` output

The output of `lakeql add <feature>` is easier to read. Each follow-up step is numbered, separated by a blank line, and its prose is wrapped to the terminal width so long lines no longer run off-screen. Code to paste is set off from the step's prose by a blank line and syntax highlighted in colors that stay legible on both light and dark terminals, instead of a single dim gray.

`@lakeql/scaffold` groups each guidance item (env-schema and data-source wiring) into one entry with its code block, so a snippet renders under its step rather than as separate numbered lines. `@lakeql/logger` exposes the color atoms used to compose the output.
