### Suppress duplicate-name noise for unnamed fields

Adding two fields without yet typing a name no longer reports a redundant "Duplicate field name at this level" issue on the second one. An empty-named field already surfaces "Field name is invalid", so that single message now stands alone. The export gate is unchanged: two empty-named fields remain non-exportable, and two fields sharing the same non-empty name still report the duplicate.
