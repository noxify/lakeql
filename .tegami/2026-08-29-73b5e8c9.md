### Add `--target-dir` option to choose where the project is created

`create-lakeql-app` now accepts `--target-dir <path>` (alias `-d`), a parent directory the new project is created in. The project is scaffolded into `<target-dir>/<project-name>`, and the default remains the current directory. This makes it easier to generate a project into a subdirectory (for example `examples`) without changing into it first.
