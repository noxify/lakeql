### Shared per-data-source paging contract

`@lakeql/datasource` now exports the `ReadStrategyPaging` type (`{ defaultPerPage: number; maxRecordsPerPage: number }`), the resolved per-data-source paging limits that flow from config to read strategies.

`DataSourceReadInput.paging.perPage` is now optional. When a request omits it, the read strategy substitutes the resolved default. `AdapterFactory.createReadStrategy` accepts an optional `paging` argument carrying these limits; omitting it stays valid for existing and third-party implementers.
