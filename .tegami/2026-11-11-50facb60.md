### Command palette, dark mode, and canvas polish in the Endpoint Builder

`@lakeql/studio` adds a command palette to the Endpoint Builder. Press ⌘K (Ctrl-K on Windows/Linux) or the "Commands" button in the header to open it, then type to run an action: navigate to any view (General Settings, Fields, Validations, JSON), Import or Export (Export stays gated on a valid definition), jump to the open validations, add a field of any of the eight types from a nested sub-view, or reset the editor behind a confirmation. The palette is keyboard-first and closes after running a command.

A theme toggle in the header switches between light, dark, and system themes; the choice is applied across the whole shell, including the palette and other overlays, and the host app persists it. The sidebar now shows the LakeQL logo (full wordmark when expanded, icon-only when the rail collapses). The Fields view gains a content-fixed Undo/Redo toolbar that stays in reach while the field list scrolls, with keyboard undo/redo working from every view, and the redundant validation alert is gone — the blocking-issue count now lives only in the header. Keyboard field reordering no longer leaves a distorted ghost image: the reorder grip is pointer-only, and the dedicated "Move field" control remains the keyboard path. The core, the validity gate, and the exported definition format are unchanged.
