### Resolve tsconfig path aliases in lakeql.config.ts at load time

TypeScript path aliases declared in a project's `tsconfig.json` (for example the
scaffolded template's `"~/*": ["./src/*"]`) now resolve when the CLI loads
`lakeql.config.ts`. Previously an import such as `import { permissions } from "~/permissions"`
typechecked and autocompleted in the editor but failed at load time with
`Cannot find module '~/permissions'`, because the config loader did not enable
jiti's tsconfig path resolution. The loader now auto-discovers the project's
tsconfig and honors any user-defined alias, not just `~`.
